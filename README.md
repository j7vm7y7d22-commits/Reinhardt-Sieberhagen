# Three-Axis Bite-Force Sensor

**Final-Year Mechatronics Engineering Project – Stellenbosch University**

## Project Overview

This project focuses on the design and development of a passive, low-profile, three-axis bite-force sensor for measuring mandibular loads.

The system integrates mechanical force-sensing elements, strain gauges and embedded electronics to measure forces in three dimensions. MATLAB modelling is used to estimate idealised temporomandibular joint (TMJ) reaction forces from measured bite forces.

## Key Components

- Mechanical design and strain-gauge instrumentation
- Three-axis force measurement
- STM32-based embedded electronics
- HX711 load-cell amplifiers
- MATLAB modelling and data analysis
- Sensor calibration and experimental validation

## Objective

To develop and experimentally evaluate a compact sensor system capable of measuring three-dimensional bite forces and providing input for mandibular load analysis.
